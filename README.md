# Agenc-IA

Web comercial de Agenc-IA, agencia de implementacion de agentes IA personalizados para ventas, atencion al cliente y automatizacion operativa.

## Stack

- Vue 3
- Vite
- TypeScript
- SCSS
- GSAP + Lenis
- Three.js
- Vercel Functions para reenvio seguro de leads a n8n

## Variables

Configurar en Vercel:

- `AGENCIA_IA_N8N_LEAD_WEBHOOK_URL`
- `AGENCIA_IA_N8N_WEBHOOK_TOKEN`

## Scripts

```bash
pnpm install
pnpm build
pnpm dev
```
